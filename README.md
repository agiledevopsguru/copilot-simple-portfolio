# Nandan P Aghera Portfolio

A responsive, static developer portfolio built with semantic HTML, CSS, and vanilla JavaScript. The visual direction uses a clean white layout, teal accents, a subtle geometric hero, and small scroll-based transitions.

## Features

- Hero, About Me, Skills, Projects, Work Experience, and Contact sections
- Responsive navigation with a mobile menu
- Skills for Flutter, Dart, REST APIs, Git, Docker, AWS, Linux, and GitHub Actions
- CSS-only geometric hero illustration and project previews
- Scroll reveal animations with an accessible fallback
- No paid APIs, backend services, build tools, or runtime dependencies

## Setup

No installation is required. Clone or download the repository, then open `index.html` in a browser.

For a local development server, run one of the following from the project folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customization

- Update the profile copy, links, and project details in `index.html`.
- Adjust the design tokens at the top of `style.css`.
- Replace the placeholder GitHub and LinkedIn URLs with your own profiles.
- Replace `hello@nandanaghera.dev` with your preferred contact address.

The Google Fonts import is optional. The page keeps local fallback fonts and remains usable if external font loading is unavailable.
